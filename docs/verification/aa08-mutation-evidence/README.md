# AA-08 mutation evidence

This directory intentionally contains no passing mutation logs. The former
artifacts were generated by dry-run simulation, so they did not prove that any
test killed a mutant. They were removed rather than retained as acceptance
evidence.

`manifest.json` records the current honest state: control and mutation tests
have not been executed for this checkout. Run
`tool/ci/run_targeted_mutations.py` without `--dry-run` to generate live JUnit
evidence. A dry run validates patch creation and restoration only; it exits
non-zero, records every mutation as `NOT_EXECUTED`, and sets `verified` to
`false`.

Every invocation writes to a unique `run-<timestamp>-<mode>-<id>` child
directory. The runner hashes only that child. It does not delete, overwrite, or
re-sign prior runs, this README, or other files in the evidence root.
