`test/diagnostics/service_recipes/mode08_d05_supplement_test.dart`. That host test

proof that the APK executed. Their checksums still match: integrity cannot change
the evidence layer. This conclusion comes from the generator source, not an
inference about an author's intent.

The regression is retained as explicitly named **host-only TCP/Notifier** tests.
